# المرصد الوطني للإحصاءات والمؤشرات السياحية

منصة عربية باتجاه **RTL** لإدارة وتحليل وعرض الإحصاءات والمؤشرات السياحية الوطنية والمدنية، وفق أطر **UN Tourism** ومؤشرات أهداف التنمية المستدامة SDG 8 و11 و12 و14 و17. تعتمد المنصة مركز المعلومات والتوثيق السياحي بوصفه المصدر المرجعي المركزي، وتفصل بوضوح بين المسودة والمراجعة المستقلة والاعتماد والنشر.

> لا تُعامل القيم التنبؤية أو البيانات الجزئية على أنها حقائق منشورة. لا تُعرض الواجهات العامة إلا القياسات المعتمدة.

## الوظائف الرئيسية

| المجال | ما توفره المنصة |
|---|---|
| المؤشرات والقياسات | تعريف مؤشرات UN Tourism وSDG، وإدخال قياسات سنوية وربع سنوية مع مصدر ووحدة وحالة تحقق. |
| الحوكمة | دورة `draft → reviewed → approved` مع منع المراجعة الذاتية وسجل تدقيق للعمليات الحساسة. |
| المدن السياحية | خريطة مدن، وترتيب، ومقارنة، وتغير رتبة عبر السنوات، وتنبؤ مدني منفصل عن القيم المعتمدة. |
| التقارير | تصدير جداول ورسوم إلى Excel وPDF، وتقارير مقارنة ومدن، ولوحة دعم إدارية قابلة للتصفية والتصدير. |
| المساعدة والدعم | دليل قابل للبحث، وأسئلة شائعة حسب الدور، ومساعد ذكي مقيد بالدليل، وتذاكر دعم ومرفقات وردود وإشعارات. |
| الوصول والتفضيلات | وضع ليلي، حجم خط، تباين أعلى، تقليل حركة، وتفضيلات لإشعارات الدعم. |
| الأمن | صلاحيات إدارية دقيقة، حماية جلسات، حدود طلبات، مراجعة تبعيات تقريرية، وسياسة ترقية يدوية عبر بيئة اختبار منفصلة. |

## الأدوار

| الدور | الاستخدام المتوقع |
|---|---|
| `viewer` | قراءة البيانات واللوحات والتقارير المسموح بها، واستخدام المساعدة والدعم. |
| `analyst` | إدخال قياسات ومسودات، استيراد البيانات، والمراجعة المستقلة للقياسات التي لم يدخلها. |
| `admin` | اعتماد القياسات المراجعة، إدارة الدعم والمستخدمين ضمن التفويض الصريح، واعتماد الإصدارات وفق القدرة المحددة. |

لا تكفي صفة `admin` وحدها لبعض العمليات الحساسة؛ فالتحكم في الأدوار ومراجعة الأمان واعتماد الإصدارات مقيد بقائمة أعضاء إدارية مفوضة صراحة، بينما يحتفظ مالك المنصة بقدرة التهيئة الأولية.

## البنية التقنية

تستخدم المنصة React 19 وTypeScript وTailwind 4 في الواجهة، وExpress وtRPC في الخادم، وMySQL/TiDB مع Drizzle ORM للبيانات. تتم المصادقة عبر Manus OAuth، وتخزن المرفقات في S3 مع حفظ بياناتها الوصفية فقط في قاعدة البيانات.

```text
client/                 واجهة React وصفحات لوحة التحكم
server/                 tRPC، منطق الحوكمة، وخدمات الخادم
drizzle/                المخطط وترحيلات قاعدة البيانات
shared/                 تحقق الوحدات ونماذج البيانات المشتركة
storage/                أدوات التخزين الآمن
```

## التشغيل المحلي

### المتطلبات

يلزم Node.js 22 أو أحدث وpnpm 10 أو أحدث، إضافة إلى قاعدة MySQL/TiDB قابلة للوصول. يتطلب تسجيل الدخول محلياً إعداد Manus OAuth متوافقاً مع عنوان التشغيل المحلي.

```bash
git clone https://github.com/tidclibya2026/tourism-statistics-sdg.git
cd tourism-statistics-sdg
pnpm install
```

أنشئ ملف `.env` محلياً لا يُرفع إلى GitHub، ثم وفر القيم التالية من بيئة التطوير المصرح بها:

```dotenv
DATABASE_URL=mysql://USER:PASSWORD@HOST:PORT/DATABASE
JWT_SECRET=local-development-secret
VITE_APP_ID=your-oauth-app-id
OAUTH_SERVER_URL=https://api.manus.im
OWNER_OPEN_ID=your-owner-open-id
BUILT_IN_FORGE_API_URL=https://api.manus.im
BUILT_IN_FORGE_API_KEY=your-server-side-forge-key
TOURISM_DEPLOYMENT_ENV=development
```

> لا تنسخ قيم الإنتاج إلى جهاز تطوير شخصي، ولا ترفع `.env` أو مفاتيح S3 أو رموز OAuth إلى المستودع.

طبّق الترحيلات بعد مراجعة ملفات SQL التي ولّدها Drizzle، ثم شغّل الخادم:

```bash
pnpm db:push
pnpm dev
```

بعد التشغيل، يتيح الخادم واجهة التطوير على المنفذ الذي يحدده البيئة. لا تستخدم قيمة منفذ ثابتة في نشر الإنتاج.

## الأوامر اليومية

| الأمر | الغرض |
|---|---|
| `pnpm dev` | تشغيل بيئة التطوير مع إعادة تحميل. |
| `pnpm check` | فحص TypeScript من دون توليد ملفات. |
| `pnpm test` | تشغيل اختبارات Vitest. |
| `pnpm build` | بناء الواجهة والخادم للإنتاج. |
| `pnpm start` | تشغيل ناتج البناء في وضع الإنتاج. |
| `pnpm audit --prod` | تقرير تدقيق تبعيات الإنتاج فقط؛ لا يغير الحزم. |
| `pnpm audit --json` | تقرير كامل، يشمل أدوات التطوير؛ لا يغير الحزم. |

## البيانات وحوكمة النشر

1. يعرّف المسؤول المؤشر ووحدته ومنهجيته ومصدره.
2. ينشئ المحلل قياساً أو يستورد صفاً كمـسودة موثقة.
3. يراجع محلل مستقل القياس، ولا يستطيع مراجعة قياسه الشخصي.
4. يعتمد المسؤول القياس المراجع فقط.
5. تقرأ الواجهات العامة والخرائط والتقارير القياسات `approved` فقط.

لا تربط وجهات Visit Libya أو أطلس ليبيا خارجياً قبل تهيئة endpoint وعقد بيانات ومصادقة وبيئة اختبار مستقلة وموافقة صريحة من مالك المنصة.

## الحساب والإشعارات

توجد صفحة **الملف الشخصي والإعدادات** لتحديث الاسم الظاهر وتفضيلات إشعارات الردود وتغيرات حالة طلبات الدعم. تدير Manus OAuth كلمة المرور والاسترداد؛ لذلك لا تخزن المنصة كلمة مرور محلية ولا توفر حقل تغيير كلمة مرور داخل قاعدة البيانات.

## الأمان والتبعيات

سياسة المشروع تقريرية: لا تشغّل `pnpm update` أو `pnpm audit fix` تلقائياً، ولا تطبق أي تحديث على الحي بلا اعتماد بشري واختبارات في بيئة اختبار منفصلة. راجع ملف [`security_audit_report_2026-08-26.md`](./security_audit_report_2026-08-26.md) لنتائج التدقيق الحالية وخطة المعالجة اليدوية.

## النشر

احفظ نقطة استعادة بعد كل مجموعة تغييرات، ثم نفذ النشر يدوياً من زر **Publish** في واجهة إدارة المشروع فقط بعد اجتياز الاختبارات واعتماد نتائج تدقيق الأمان. لا يتضمن المستودع أسرار الإنتاج أو بيانات قاعدة البيانات.

> **قرار التشغيل الحالي:** المنصة للاستخدام الداخلي الخاص داخل المركز فقط. راجع [`internal_use_and_publication_policy.md`](./internal_use_and_publication_policy.md) قبل أي قرار لاستضافة أو نطاق أو وصول عام.
